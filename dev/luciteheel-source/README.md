# Lucite heel pump

Original code-native transparent beveled prism, authored in `dev/build-luciteheel-assets.py`; this is not generated raster art or new anatomy.

The accepted stiletto6 product and worn paintings supply the upper/arch and their immutable camera. Only the distal stem band is replaced with perspective-specific low-alpha mint glass, soft rose/cream reflected facets, a tiny champagne upper mount and the original painted contact cap. Outside that band every encoded RGBA pixel is identical. Skin and occlusion files are byte-identical to the accepted smooth source.

Regenerate with `python3 dev/build-luciteheel-assets.py`. Runtime layers write through temporary files followed by atomic replacement. `anchors.json` and `export.json` record the independent product/worn geometry, transparency counts and fixed toe/floor coordinates. `export-contact.jpg` shows both cameras on light and dark.

Glass uses static local alpha compositing: backgrounds show through the pane. It does not implement physical refraction or change heel height. All selected colors, materials, motifs and optional ornaments stay on the accepted shoe surfaces.
