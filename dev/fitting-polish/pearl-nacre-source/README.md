# Product Pearl nacre source repair

Immutable pre-repair product charm layers. Rebuild with
`python3 dev/fitting-polish/repair-product-pearl-nacre.py` after original
accessory, heel-height and platform exporters. The script starts from these
immutable files, so repeated runs are deterministic.

The retained original paintings in `dev/accessory-edits/` contain clean nacre.
The original extractor rejected its pink/blue mids as lilac shoe fabric and
opened holes through the pearl. Camera-registered source RGB restores only
measured nacre ellipses. Neutral source highlights remain; key-green source
matte is rejected. Gold chain holes outside those semantic cores remain exact.

Full artwork bounds/mount and every pixel outside the recorded semantic masks
stay exact. Some damaged nacre contours were open to the exterior, so individual
column visible limits intentionally change to restore the source pearl outline.
No shoe/body/skin/hosiery or unrelated ornament is edited.

Native light/dark before/after, semantic masks, changed-pixel counts and final
SHA256 values are in `qa/pearl-nacre/`. These verify scoped source repair;
full20-style art parity remains subject to native review.
