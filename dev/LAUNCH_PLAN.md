# 甜甜小鞋铺 上线计划 — CrazyGames 独占加成

来源：CrazyGames Developer Terms 2026-04-14，第 5.5 条
https://files.crazygames.com/documents/developer_terms_20260414.pdf

## 条款要点
- 默认非独占；独占是开发者主动选择（opt-in）。
- 选择独占：Full Launch 当天起 2 个月，游戏只在 CrazyGames 一个网页游戏站上提供，且由 CrazyGames 托管 → 这 2 个月收益 +50%。
- 独占只算“网页游戏网站”；Steam、Apple App Store、Google Play 不算，可以同时上。
- Basic Launch（约 7–21 天小范围测试）没有广告收益，独占期从 Full Launch 才开始算。

## 决定（2026-10-27，用户同意排进计划）
- 计划选择 2 个月独占（Full Launch 时在开发者后台 opt in）。
- 独占期内不上：Poki、GameDistribution、itch.io 网页版、GamePix、Y8、CoolMathGames 等任何网页游戏站，以及自建公开可玩网页。
- 可以上：iOS / Android 应用商店、Steam（若以后做）。
- 公开试玩链接（raw.githack / GitHub 预览）：用户 2026-10-27 20:40 确认，Full Launch 前下线（删除 sweet-shoe-preview 分支上的可玩文件或把仓库设为私密）。打磨期和 QA 期间照常使用。
- 独占期结束（Full Launch + 2 个月）后再评估其他网页站。

## 时间线（日期待 Full Launch 确定后填）
1. 2026-10-28 22:30 CST 打磨截止 → 打包提交 QA。
2. QA 通过 → Basic Launch（无收益，看数据）。
3. Full Launch 当天：后台 opt in 独占；记录日期 D。
4. D 前：下线公开试玩链接。
5. D + 2 个月：独占结束，评估 Poki 等。
